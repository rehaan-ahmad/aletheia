# Security Policy

## Supported Versions
Ensure you are running the latest version of the repository main branch.

## Reporting a Vulnerability
At Aletheia, we take the security of our fact-checking pipeline seriously. We implement the **AthenaGuard Security Framework** internally to prevent unintended vulnerabilities across XSS, injection vectors, and data privacy domains.

If you have discovered a security vulnerability in this project, please follow these guidelines:

1. **Do not disclose the vulnerability publicly.**
2. Send an email to the project maintainer outlining precisely how to replicate the vulnerability.
3. We will acknowledge receipt of your vulnerability report in 48 hours and strive to issue a patch within 72 hours.

Note: We specifically monitor reports regarding prompt injection methodologies affecting Gemini and our LangGraph state machine. Let us know if our constraints are demonstrably bypassed!
